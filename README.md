# DefectSense AI

Monorepo root for the industrial defect detection stack.

**All application code lives in [`defectsense-ai/`](defectsense-ai/README.md).**

```bash
cd defectsense-ai
docker compose up --build
```

See [defectsense-ai/README.md](defectsense-ai/README.md) for full setup, API reference, and deployment details.
